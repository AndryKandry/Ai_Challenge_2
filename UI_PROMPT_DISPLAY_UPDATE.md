# Обновление UI: Отображение текста запросов и ответов

## Что добавлено

В карточки результатов тестов добавлено отображение полного текста запросов и ответов для лучшего понимания того, что именно тестировалось.

## Новые элементы в `TestResultCard`

### 1. **Текст запроса** (серая панель 📝)

```
┌────────────────────────────────────────┐
│ 📝 Запрос:                             │
│   What is the capital of France?       │
└────────────────────────────────────────┘
```

**Особенности:**
- Серый фон `Color(0xFFF5F5F5)` для нейтральности
- Тёмно-серый текст `Color(0xFF616161)` для хорошей читаемости
- Показывает полный текст запроса
- Отображается для всех типов запросов (SHORT/LONG/EXCEEDING_LIMIT)

### 2. **Ответ модели** (зелёная панель 💬)

```
┌────────────────────────────────────────┐
│ 💬 Ответ модели:                       │
│   The capital of France is Paris...    │
└────────────────────────────────────────┘
```

**Особенности:**
- Зелёный фон `Color(0xFFE8F5E9)` для визуального выделения ответа
- Тёмно-зелёный текст `Color(0xFF1B5E20)`
- Ограничение первыми 500 символами с добавлением "..." для длинных ответов
- Показывается только если ответ не пустой
- Помогает понять качество и полноту ответа модели

## Примеры для разных типов запросов

### SHORT (Короткий запрос)
```kotlin
📝 Запрос:
  What is the capital of France?

💬 Ответ модели:
  The capital of France is Paris.
```

### LONG (Длинный запрос)
```kotlin
📝 Запрос:
  Please provide a comprehensive analysis of the following topic:
  The impact of artificial intelligence on modern software development...
  (показывается полный текст)

💬 Ответ модели:
  Here's a comprehensive analysis:
  1. How AI is changing code development...
  (первые 500 символов с "...")
```

### EXCEEDING_LIMIT (Превышение лимита)
```kotlin
📝 Запрос:
  This is an intentionally long prompt designed to exceed...
  (первые 200 символов - обрезается ещё в PromptTestResult)

💬 Ответ модели:
  (может быть пустым при ошибке или показывать результат после обрезки)
```

## Технические детали

### Код изменений

```kotlin
// Текст запроса
Surface(
    shape = RoundedCornerShape(4.dp),
    color = Color(0xFFF5F5F5),
    modifier = Modifier.fillMaxWidth().padding(bottom = 8.dp)
) {
    Column(modifier = Modifier.padding(12.dp)) {
        Text(
            text = "📝 Запрос:",
            fontSize = 11.sp,
            fontWeight = FontWeight.Bold,
            color = Color(0xFF424242),
        )
        Text(
            text = result.promptText,
            fontSize = 11.sp,
            color = Color(0xFF616161),
            lineHeight = 16.sp,
        )
    }
}

// Текст ответа (только если не пустой)
if (result.responseText.isNotBlank()) {
    Surface(
        shape = RoundedCornerShape(4.dp),
        color = Color(0xFFE8F5E9),
        modifier = Modifier.fillMaxWidth().padding(bottom = 8.dp)
    ) {
        Column(modifier = Modifier.padding(12.dp)) {
            Text(
                text = "💬 Ответ модели:",
                fontSize = 11.sp,
                fontWeight = FontWeight.Bold,
                color = Color(0xFF2E7D32),
            )
            Text(
                text = result.responseText.take(500) +
                      if (result.responseText.length > 500) "..." else "",
                fontSize = 11.sp,
                color = Color(0xFF1B5E20),
                lineHeight = 16.sp,
            )
        }
    }
}
```

### Используемые поля из `PromptTestResult`

- `result.promptText` - текст запроса (уже обрезан до 200 символов в PromptComparison)
- `result.responseText` - полный текст ответа от модели

## Преимущества

1. **Наглядность** 📊
   - Теперь видно не только метрики, но и сам контент
   - Можно оценить качество ответа визуально
   - Понятно, какие именно запросы отправлялись

2. **Отладка** 🐛
   - Легче найти причину проблем с конкретными запросами
   - Видно как модель обработала длинные/короткие запросы
   - Можно проверить корректность трансформаций

3. **Анализ** 🔍
   - Сравнение ответов на разные типы запросов
   - Оценка полноты ответа не только по метрикам
   - Понимание поведения модели в разных сценариях

4. **UX** ✨
   - Цветовое кодирование (серый = запрос, зелёный = ответ)
   - Эмодзи для быстрой визуальной навигации
   - Ограничение длины ответа предотвращает перегрузку UI

## Адаптивность

- **Короткие тексты**: отображаются полностью
- **Длинные запросы**: обрезаются до 200 символов ещё в `PromptTestResult`
- **Длинные ответы**: обрезаются до 500 символов с добавлением "..."
- **Пустые ответы**: панель с ответом не показывается

## Совместимость

- ✅ Работает со всеми провайдерами (Claude, HuggingFace, Yandex GPT)
- ✅ Корректно отображает все типы запросов (SHORT/LONG/EXCEEDING_LIMIT)
- ✅ Поддерживает все статусы (success/truncated/error)
- ✅ Совместимо с существующей системой метрик
