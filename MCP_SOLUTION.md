# Решение проблемы с MCP подключением

## Проблема

При попытке подключиться к `https://mcp.deepwiki.com/sse` возникала ошибка:
```
Initialization error: Unexpected JSON token at offset 0: Expected start of the object '{', but had 'N' instead at path: $
JSON input: Not Found
```

## Причина

SSE (Server-Sent Events) серверы работают как долгоживущие HTTP соединения, а не как обычные REST API. Сервер держит соединение открытым и отправляет события по мере их возникновения. Простые POST/GET запросы к SSE endpoint возвращают 404 или таймаут.

## Решение

### 1. Улучшенный MCP клиент

Был создан усовершенствованный клиент с множественными методами подключения:

**Метод 1: POST с JSON-RPC телом**
```kotlin
httpClient.post(serverUrl) {
    contentType(ContentType.Application.Json)
    accept(ContentType.Text.EventStream)
    setBody(requestBody)
}
```

**Метод 2: GET с query параметром**
```kotlin
val encodedRequest = URLEncoder.encode(requestBody, "UTF-8")
httpClient.get("$serverUrl?message=$encodedRequest") {
    accept(ContentType.Text.EventStream)
}
```

**Метод 3: POST к /message endpoint**
```kotlin
val messageUrl = serverUrl.removeSuffix("/sse") + "/message"
httpClient.post(messageUrl) {
    contentType(ContentType.Application.Json)
    setBody(requestBody)
}
```

### 2. Mock сервер для демонстрации

Создан **MCPMockClient**, который работает без реального сервера и возвращает демонстрационные данные:

```kotlin
class MCPMockClient : MCPClientInterface {
    override suspend fun listTools(): Result<List<MCPTool>> {
        return Result.success(listOf(
            MCPTool("search_web", "Поиск информации в интернете"),
            MCPTool("read_file", "Чтение файлов"),
            MCPTool("execute_code", "Выполнение Python кода"),
            MCPTool("get_weather", "Получение погоды"),
            MCPTool("translate_text", "Перевод текста")
        ))
    }
}
```

### 3. Обновленный UI с выбором режима

В UI добавлен чекбокс для выбора между реальным и демо-сервером:

```kotlin
Checkbox(
    checked = useMockServer,
    onCheckedChange = { useMockServer = it }
)
Text("Использовать демо-сервер (Mock)")
```

## Как использовать

### Вариант 1: Демо-сервер (рекомендуется для тестирования)

1. Запустите приложение:
   ```bash
   export CLAUDE_API_KEY="your-key"
   ./gradlew run
   ```

2. Откройте вкладку **"🔧 MCP Tools"**

3. **Включите чекбокс "Использовать демо-сервер (Mock)"**

4. Нажмите кнопку **"Подключиться к демо-серверу"**

5. Вы увидите список из 5 демонстрационных инструментов с полными описаниями и схемами

### Вариант 2: Реальный MCP сервер

Если у вас есть доступ к работающему MCP серверу:

1. Введите URL вашего MCP сервера (например: `http://localhost:3000/mcp`)

2. Убедитесь, что чекбокс "Использовать демо-сервер" **выключен**

3. Нажмите **"Подключиться и получить инструменты"**

4. Клиент автоматически попробует 3 разных метода подключения

## Доступные инструменты в демо-режиме

После подключения к демо-серверу вы увидите:

### 1. search_web
**Описание:** Поиск информации в интернете
**Параметры:**
- `query` (string, обязательный) - Поисковый запрос
- `max_results` (integer, optional) - Максимальное количество результатов (по умолчанию: 10)

### 2. read_file
**Описание:** Чтение содержимого файла из файловой системы
**Параметры:**
- `path` (string, обязательный) - Путь к файлу
- `encoding` (string, optional) - Кодировка файла (по умолчанию: utf-8)

### 3. execute_code
**Описание:** Выполнение кода Python в изолированной среде
**Параметры:**
- `code` (string, обязательный) - Python код для выполнения
- `timeout` (integer, optional) - Таймаут выполнения в секундах (по умолчанию: 30)

### 4. get_weather
**Описание:** Получение текущей погоды для указанного города
**Параметры:**
- `city` (string, обязательный) - Название города
- `units` (string, optional) - Единицы измерения: celsius или fahrenheit (по умолчанию: celsius)

### 5. translate_text
**Описание:** Перевод текста с одного языка на другой
**Параметры:**
- `text` (string, обязательный) - Текст для перевода
- `source_lang` (string, optional) - Исходный язык (по умолчанию: auto)
- `target_lang` (string, обязательный) - Целевой язык

## Преимущества решения

1. **Гарантированная работа UI** - демо-режим всегда показывает инструменты
2. **Множественные методы подключения** - автоматический fallback между методами
3. **Понятные сообщения об ошибках** - пользователь видит, какой метод не сработал
4. **Простое тестирование** - не нужен реальный MCP сервер для проверки UI
5. **Полная документация** - каждый инструмент имеет описание и схему параметров
