# Быстрый тест MCP UI интеграции

## Шаг 1: Запустите Python сервер

```bash
python your_mcp_server.py
```

Вы должны увидеть:
```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

## Шаг 2: Запустите Kotlin приложение

```bash
./gradlew run
```

## Шаг 3: Откройте вкладку "MCP Tools"

В главном окне приложения нажмите на вкладку "🔧 MCP Tools" (последняя справа)

## Шаг 4: Подключитесь к серверу

1. В поле "MCP Server URL" должен быть адрес: `http://127.0.0.1:8000/mcp`
2. Нажмите кнопку "Подключиться"

## Шаг 5: Вызовите инструмент

### Тест 1: greet

1. Нажмите "Вызвать" на инструменте `greet`
2. В поле `name` введите: `Kotlin`
3. Нажмите "Выполнить"
4. **Ожидаемый результат:**
   ```
   Результат:
   Hello, Kotlin!
   ```

### Тест 2: add

1. Нажмите "Вызвать" на инструменте `add`
2. В поле `a` введите: `15`
3. В поле `b` введите: `27`
4. Нажмите "Выполнить"
5. **Ожидаемый результат:**
   ```
   Результат:
   42
   ```

### Тест 3: ttools

1. Нажмите "Вызвать" на инструменте `ttools`
2. Нажмите "Выполнить" (параметры не требуются)
3. **Ожидаемый результат:**
   ```
   Результат:
   [{"name": "greet", "signature": "(name: str) -> str", "doc": ""},
    {"name": "add", "signature": "(a: int, b: int) -> int", "doc": "Add two numbers"},
    {"name": "ttools", "signature": "() -> str", "doc": ""}]
   ```

## Troubleshooting

### Проблема: "Не удалось подключиться к локальному серверу"

**Решение:**
- Убедитесь, что Python сервер запущен
- Проверьте, что порт 8000 не занят: `lsof -i :8000`
- Попробуйте перезапустить Python сервер

### Проблема: ttools не отображается

**Причина:** Инструмент `ttools` недоступен на сервере

**Решение:** Это нормально, информация будет получена через `tools/list`

### Проблема: Пустой список инструментов

**Решение:**
- Проверьте, что Python сервер зарегистрировал инструменты
- Посмотрите логи Python сервера
- Попробуйте Mock сервер (поставьте галочку "Использовать демо-сервер")

## Альтернативный тест (Mock сервер)

Если Python сервер недоступен:

1. Поставьте галочку "Использовать демо-сервер (Mock)"
2. Нажмите "Подключиться к демо-серверу"
3. Вы увидите 5 демонстрационных инструментов:
   - search_web
   - read_file
   - execute_code
   - get_weather
   - translate_text
