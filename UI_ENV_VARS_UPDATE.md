# Обновление UI: Использование переменных окружения

## Изменения

### ✅ Убраны поля для ручного ввода API ключей

UI теперь **автоматически** использует переменные окружения вместо ручного ввода ключей.

### Новая функциональность

1. **Автоматическая проверка доступности провайдеров**
   - При открытии вкладки "🔢 Анализ токенов" автоматически проверяется наличие переменных окружения
   - Провайдеры без настроенных ключей становятся недоступными (серые кнопки)

2. **Визуальная индикация статуса**
   - ✅ **Зелёная плашка**: провайдер настроен и готов к использованию
   - ⚠️ **Оранжевая плашка**: провайдер не настроен, показывает какие переменные отсутствуют

3. **Информативные сообщения**
   - Для недоступных провайдеров отображается список отсутствующих переменных окружения
   - Названия переменных показываются моноширинным шрифтом для удобства копирования

## Требуемые переменные окружения

### Claude
```bash
export CLAUDE_API_KEY="your-claude-api-key"
```

### HuggingFace
```bash
export HUGGINGFACE_API_KEY="your-huggingface-api-key"
```

### Yandex GPT
```bash
export YANDEX_API_KEY="your-yandex-api-key"
export YANDEX_FOLDER_ID="your-folder-id"
```

## Использование

1. **Настройте переменные окружения** для нужных провайдеров (см. выше)

2. **Запустите приложение:**
   ```bash
   ./gradlew run
   ```

3. **Перейдите на вкладку "🔢 Анализ токенов"**

4. **Выберите доступный провайдер** (с зелёным статусом)

5. **Нажмите "▶ Запустить сравнение"**

## Технические детали

### Функция `checkAvailableProviders()`
Проверяет наличие переменных окружения при инициализации экрана:

```kotlin
fun checkAvailableProviders(): Map<String, ProviderInfo> {
    return mapOf(
        "claude" to ProviderInfo(
            name = "Claude",
            isAvailable = System.getenv("CLAUDE_API_KEY") != null,
            missingVars = listOfNotNull(
                if (System.getenv("CLAUDE_API_KEY") == null) "CLAUDE_API_KEY" else null
            )
        ),
        // ... другие провайдеры
    )
}
```

## Преимущества нового подхода

1. **Безопасность**: API ключи не хранятся в UI и не могут быть случайно показаны/скопированы
2. **Удобство**: не нужно каждый раз вводить ключи вручную
3. **Стандартизация**: использование переменных окружения - стандартная практика для конфиденциальных данных
4. **Автоматизация**: можно настроить переменные один раз в `.bashrc` или `.zshrc`

## Миграция с предыдущей версии

Если вы использовали предыдущую версию с ручным вводом ключей:

1. Скопируйте ваши API ключи
2. Установите их как переменные окружения (см. секцию "Требуемые переменные окружения")
3. Перезапустите приложение
4. Готово! Ключи больше не нужно вводить вручную

## Troubleshooting

### Кнопка "Запустить сравнение" неактивна
- Убедитесь, что все необходимые переменные окружения установлены
- Проверьте оранжевую плашку - там указано какие переменные отсутствуют
- Перезапустите приложение после установки переменных

### Ошибка "CLAUDE_API_KEY не установлен"
```bash
# Установите переменную:
export CLAUDE_API_KEY="your-key-here"

# Или добавьте в ~/.bashrc или ~/.zshrc для постоянного использования:
echo 'export CLAUDE_API_KEY="your-key-here"' >> ~/.bashrc
source ~/.bashrc
```

### Переменные не подхватываются
- Убедитесь, что вы экспортировали переменные через `export`
- Перезапустите терминал после изменения `.bashrc`/`.zshrc`
- Проверьте переменные командой: `echo $CLAUDE_API_KEY`
